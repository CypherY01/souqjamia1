# عقد التحديث الفوري (Realtime)

يحل محل API065 حسب القسم 5 من الملحق. التحديث يتم عبر Supabase Realtime بقنوات خاصة (private channels) محمية بسياسات RLS.

الحالة: معتمد من المالك مع المهمة 1.1 في 18 نوفمبر 2026.

## المبادئ

1. **الحدث تنبيه بلا محتوى.** لا يحمل نص رسالة ولا اسماً ولا مبلغاً ولا رابط صورة. العميل يجلب البيانات من REST، والخادم يعيد فحص الصلاحية هناك (الفصل 07، FR40).
2. **يُنشر بعد نجاح المعاملة فقط.** يُرسل من داخل دوال `app` نفسها، فلا يصل حدث لكتابة لم تلتزم (TC40).
3. **REST هو المصدر.** عند الاشتراك، أو إعادة الاتصال، أو اكتشاف فجوة في `message_seq`، يجلب العميل من آخر تسلسل مؤكد عبر API054 (FR40، FR41، TC42).
4. **الصلاحية تُفحص عند الانضمام للقناة.** رمز الوصول صالح عشر دقائق (DEC38). ولأن الحدث بلا محتوى، الاشتراك القديم لعضو قُيّد للتو لا يكشف إلا توقيت حدث، والجلب بعده يُرفض.
5. **الخروج يغلق القنوات.** عند الخروج أو إلغاء الجلسة يغلق العميل كل القنوات الخاصة (FR49، TC56).

## القنوات

| القناة | من يشترك | شرط الانضمام في RLS |
| --- | --- | --- |
| `conversation:{conversation_id}` | طرفا المحادثة | المشترك عضو في ConversationMember لهذه المحادثة، وبريده مؤكد، وحسابه نشط وليس بانتظار الحذف |
| `user:{profile_id}` | صاحب الحساب فقط | `profile_id` هو ملف المشترك نفسه، بنفس شروط الحساب |

الحظر بين العضوين لا يمنع الانضمام لقناة المحادثة، لأن قراءة السجل تبقى مسموحة (BR30). لكنه يمنع كتابة رسائل جديدة، فلا تصدر أحداث `message.created` جديدة.

## شكل الحدث

كل حدث بث (broadcast) يحمل الحقول المشتركة:

```json
{ "type": "message.created", "v": 1, "conversation_id": "<uuid>", "message_seq": 42 }
```

### على قناة المحادثة

| النوع | الحقول | ما يفعله العميل |
| --- | --- | --- |
| `message.created` | `conversation_id`، `message_seq` | يجلب من آخر تسلسل لديه عبر API054 |
| `offer.changed` | `conversation_id`، `offer_id`، `status`، `version` | يحدّث بطاقة العرض بجلب الرسائل أو المحادثة |
| `meetup.changed` | `conversation_id`، `meetup_id`، `status`، `version` | يحدّث بطاقة اللقاء |
| `deal.changed` | `conversation_id`، `deal_id`، `status`، `version` | يجلب الصفقة عبر API068 |
| `context.changed` | `conversation_id` | يجلب المحادثة عبر API053 (بيع، إغلاق، إخفاء) |

### على قناة المستخدم

| النوع | الحقول | ما يفعله العميل |
| --- | --- | --- |
| `inbox.changed` | `conversation_id`، `last_seq` | يحدّث صندوق المحادثات وعدّ غير المقروء عبر API052 |
| `read.changed` | `conversation_id`، `last_read_seq` | يزامن مؤشر القراءة بين أجهزة نفس العضو (FR64) |
| `notifications.changed` | لا شيء | يجلب العدد عبر API115 |

## خارج المرحلة الأولى أو خارج المواصفات

- لا مؤشر «يكتب الآن» ولا حضور (presence)، لأن المواصفات لا تطلبهما.
- حد خمسة اتصالات فورية للعضو (RL12) يُستبدل بحدود Supabase Realtime للمشروع (DEC47).

## الاختبارات المرتبطة

- **TC12:** عضو ثالث لا يستطيع الانضمام لقناة محادثة ليس طرفاً فيها.
- **TC17:** بعد الحظر لا تُلتزم رسائل جديدة، فلا تصدر أحداثها.
- **TC40:** المعاملة الفاشلة لا تُصدر أي حدث.
- **TC42 (معدّل):** الانضمام بلا صلاحية يُرفض، والخروج يغلق القناة، وإعادة الاتصال تسترجع الفجوة عبر REST.
- **TC67:** الحساب الموقوف لا يستطيع الانضمام بعد تجديد رمزه، وجلبه عبر REST يُرفض فوراً.

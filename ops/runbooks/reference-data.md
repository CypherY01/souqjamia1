## إضافة فئة ثامنة أو أكثر

الفئات السبع ثابتة بنوع enum (`public.category_key`)، فلا تضيفها لوحة الإدارة: API095 يرفض إضافة فئة دائماً (البند 6 في `plan/task-2.3.md`). إضافة فئة تغيير قاعدة (BR03)، فتمر بالخطوات كلها معاً:

1. **القرار:** يسجّل المالك قراراً جديداً في آخر `docs/addendum-v3.1.md` (DEC48)، فيه المفتاح والتسمية العربية والإنجليزية وترتيب العرض.
2. **هجرتان جديدتان، لا تعديل هجرة قديمة:**
   - **الأولى:** `alter type public.category_key add value '<المفتاح>';`
   - **الثانية:** `insert into public.category (key, label_ar, label_en, display_order, source_ref) values (...);`، و`source_ref` يذكر رقم القرار.
   - **لماذا هجرتان:** Postgres لا يسمح باستخدام قيمة enum جديدة في نفس المعاملة التي أضافتها، وكل ملف هجرة معاملة واحدة.
3. **`packages/domain/src/enums.ts`:** المفتاح الجديد في `CategoryKey`، بنفس الترتيب في النوع.
4. **العقد:** المفتاح في `CategoryKey` في `contracts/components/schemas.yaml`، مع إضافة في `contracts/README.md` ورفع إصدار العقد.
5. **الاختبارات:**
   - `tests/integration/reference-data.test.ts`: عدد الفئات وتسمياتها المتوقعة.
   - اختبارا `enums` يفشلان حتى تتطابق القاعدة و`packages/domain` والعقد، فلا تُنسى خطوة.
6. **الواجهة:** أيقونة الفئة وموضعها في الصفحة الرئيسية وفلاتر السوق، إن وُجدت لكل فئة.
7. **التحقق:** `pnpm db:reset` ثم `pnpm test:integration` و`pnpm test` و`pnpm check:contract-ids`.

حذف فئة أصعب: قيمة enum لا تُحذف، والإعلانات تشير إليها. يُعطَّل الصف بـ `is_active = false` بدل حذفه.
